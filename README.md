# 🌮 Little Taco Shop

Hey there! 👋 Welcome to my **Little Taco Shop** repository. 

I built this project as part of my web development learning journey to practice front-end design, semantic structuring, and styling. It’s a multi-page restaurant website designed to look clean, welcoming, and fully responsive across devices.

## 🌟 What's Inside?

- **Multi-Page Layout:** Features a home page (`index.html`), an about page (`about.html`), store hours (`Hours.html`), and a contact page (`Contact.html`).
- **Responsive Design:** Crafted to adapt smoothly whether you're viewing it on a desktop or a phone.
- **Clean Structure:** Organized with semantic HTML elements and custom CSS styling.

## 🛠️ Tech Stack

- **HTML5** (~65.4%)
- **CSS3** (~33.7%)
- **JavaScript** (~0.9%)
